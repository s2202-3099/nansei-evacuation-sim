# 南西諸島 住民避難シミュレータ

先島諸島（宮古8島・八重山10島／住民112,335人）の島外避難を、航空機・船舶・ヘリコプターのアセット数から輸送力を積み上げて日次で解く図上検討用モデルです。

## これは何か

- 空港の駐機スポット数から算出した便数上限（93便/日）
- 母港からの往復サイクル（呉4日・横須賀5.5日など、前進配置なし）
- 即応機動連隊5個の展開輸送との船腹・ヘリ・スロットの競合
- 沖縄経由と九州直行の並行運用
- 受入先の収容力（住民のみが消費、観光客は自宅へ帰る）
- 決心から着手までの日数と、攻撃開始までの猶予

これらを組み込み、モンテカルロ（着手日数は対数正規、猶予は指数分布）と感度分析（PRCC・中央値分割）で結果の分布と各パラメータの寄与を出します。

## 出所

- 内閣官房国家危機管理室「沖縄県の離島からの住民避難・受入れに係る取組」（令和8年3月／令和7年3月）
- 人口：住民基本台帳 令和7年1月1日現在
- 部隊編成・保有装備：公表資料

座席数、ソーティ数、回転日数、収容人員、可動率、スポット回転率、観光客の平均在島日数は**公表されていないため推定値**です。既定値は政府資料の「1日約2万人」を再現するよう較正していますが、一点で合わせたにすぎません。

## 注意

- 本モデルは個人による非公式な図上検討であり、政府・自治体・自衛隊・海上保安庁のいかなる見解も代表しません。
- 日数の絶対値ではなく、パラメータを振ったときの感度の順序を読む道具として使ってください。
- 避難指示の発令遅延、島内の道路輸送、保安検査の処理速度、受入側の地上輸送は含んでいません。

## 技術

単一HTMLファイル。地図はLeaflet（cdnjs）とCARTOタイルを使い、取得できない環境では内蔵のベクター海岸線（24ポリゴン）に自動で切り替わります。サーバ処理もデータ収集も一切ありません。
